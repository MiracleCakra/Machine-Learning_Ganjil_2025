## Overview

This repository contains a complete set of practical implementations covering fundamental to advanced topics in machine learning, including data preprocessing, feature extraction, clustering algorithms, regression analysis, classification techniques, and deep learning architectures. Each module includes hands-on practice (P) and assignment (TG/TP) notebooks with real-world datasets.

## Key Projects

### Day-Night Image Classifier

**Location:** `JS15/daynight-classifier-CakraWangsaM.A.W-2341720032/`

A deep learning application utilizing Convolutional Neural Networks for binary image classification (day vs night scenes). Includes:

- Pre-trained H5 model
- Flask web application
- Docker containerization
- REST API implementation

### PBL Group Project

**Location:** `PBL_KELOMPOK2/`

Comprehensive machine learning project featuring:

- Extensive train-test split analysis (90-10, 95-5, 80-20, 70-30, 60-40, 50-50, 40-60, 30-70, 20-80)
- Performance evaluation across different data distributions
- Detailed analysis reports and findings
